## 조건문과 비교연산자

if문

```kotlin
fun main(){

    var a = 7
    
    if(a > 10){
        println("a는 10보다 크다")
    }else{
        println("a는 10보다 작거나 같다")
    }
}
```

참과 거짓은 비교연산으로 구할 수 있다

 ```kotlin
 fun main(){

 }
 fun dowhen(a:Any){
    when(a){
        //조건값들
    }
 }

 when -> when은 if와 비슷하면서도 다르다. 조건을 검사하여 수행한다는 점은 비슷하지만 if와 달리 조건식이 아닌 조건을 검사할 값이 들어간다
 ```

비교 연산자는 다 비슷비슷하다.
