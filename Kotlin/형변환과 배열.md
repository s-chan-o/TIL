## 형변환과 배열

**형변환** 은 하나의 변수에 지정된 자료형을 화환되는 다른 자료형으로 변경하는 기능

> 형변환 함수

- toByte()

- toShort()

- toInt()

- toLong()

- toFloat()

- toDouble()

- toChar()

```kotlin
fun main(){

    var a: Int = 54321

    var b: Long = a.toLong() //명시적 형변환
}

명시적 형변환: 변환될 자료형을 개발자가 직접 지정함
```

> 배열

```kotlin
fun main(){

    var intArr = arrayOf(1, 2, 3, 4, 5)

    var nullArr = arrayOfNulls<Int>(5) //null로 채워진배열

    intArr[2] = 8

    println(intArr[4])
}
```
