## 타입추론과 함수

**타입추론** 

변수나 함수들을 사용할때나 연산을 할때 자료형을 코드에 명시하지 않아도 자료형을 알아서 추론해주는 기능

```kotlin
fun main(){

    var a = 1234
    var b = 1234L

    var c = 12.45
    var d = 12.45f

    var e = 0xABCD
    var f = 0b01010101

    var g = true
    var h = 'c'
}
```

---

**함수**

특정한 동작을 하거나 원하는 결과값을 연산하는데 사용하는 기능

```kotlin
fun main(){

    println(add(5, 6, 7))
}

fun add(a: Int, b: Int, c: Int): Int{
    return a + b + c
}
```

```kotlin
fun main(){

    println(add(5, 6, 7))
}

fun add(a: Int, b: Int, c: Int) = a + b + c
```

자료형이 결정된 변수라는 개념으로 접근하면 좋다
