## 변수와 자료형

변수는 var과 val로 선언한다.

**var** 

일반적으로 통용되는 변수로, 언제든지 읽기 쓰기가 가능하다.

---

**val**

선언시에만 초기화 가능하고 중간에 값을 변경할 수 없다.

---

> 변수 선언

```kotlin
fun main(){

    var a: Int = 123
    println(a)
}
```

```kotlin
fun main(){

    var a: Int
    a = 123
    println(a)
}
```
```kotlin
fun main(){

    var a:Int? = null
}

var a:Int? = null -> null을 허용하는 nullable 변수 (주의해서 사용)
```

> 자료형

자료형은 자바와의 호환을 위해 거의 비슷하다.

```kotlin
fun main(){
    val stringValue = "hello"

    val multiLineStringValue = """multiLine
    string
    test"""
    //여러줄의 문자열은 " X 3 사용
}
```
