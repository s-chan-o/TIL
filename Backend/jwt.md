## JWT

JWT는 Json Web Token의 약자로 일반적으로 클라이언트와 서버 사이에서 통신할 때 권한을 위해 사용하는 토큰이다.
Json형태로 주고 받기 위해 암호화 되어있고 복잡하고 읽을 수 없는 String 형태로 되어있다.

> 구성요소

- 헤더(Header) : 어떤 알고리즘으로 암호화 할 것인지, 어떠한 토큰을 사용할 것인가의 정보가 들어있다.

- 정보(Paylod) : 전달하려는 정보가 들어있고 Payload에 있는 내용은 수정이 가능하다. 그래도 인증이 필요한 최소한의 정보만 담아야한다.

- 서명(Signature) : 헤더와 정보를 합친 후 발급해준 서버가 지정한 secret key로 암호화 시켜서 토큰을 변조하기 어렵게 만들어준다.

> 동작원리

1. 사용자가 id, password를 입력하여 로그인을 요청함

2. 서버는 회원 DB에 들어가 있는 사용자인지 확인함

3. 확인이 되면 서버는 로그인 요청 확인 후, secret key를 통해 토큰을 발급함

4. 이것을 클라이언트에게 지급함

5. 서버는 클라이언트에게 서비스 요청과 권한을 확인하기 위해 헤더에 데이터(JWT)를 요청함

6. 데이터를 확인하고 JWT에서 사용자 정보를 확인함

7. 클라이언트 요청에 대한 응답과 요청한 데이터를 전달해줌
