## 캐시(Cache)

캐시란 자주 사용하는 데이터나 값을 미리 복사해 놓는 임시 장소이다. 
캐시는 저장 공간이 작고 비용이 비싼 대신 빠른성능을 제공한다.

캐시는 

- 접근 시간에 비해 원래 데이터를 접근하는 시간이 오래 걸리는 경우

- 반복적으로 동일한 경과를 돌려주는 경우

와 같은 경우에 사용을 고려하면 좋다.

#### Local Cache

- Local장비 내에서만 사용되는 캐시로, Local장비의 Resource를 이용한다.

- Local에서만 작동하기 때문에 속도가 빠르다.

- Local에서만 작동하기 때문에 다른 서버와 데이터 공유가 어렵다.

#### Global Cache

- 여러 서버에서 Cache Server에 접근하여 사용하는 캐시로 분산된 서버에서 데이터를 저장하고 조회할 수 있다.

- 네트워크를 통해 데이터를 가져오므로, Local Cache에 비해 상대적으로 느리다.

- 별도의 Cache서버를 이용하기 때문에 서버 간 데이터 공유가 쉽다.
