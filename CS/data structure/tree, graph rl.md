# 트리, 그래프 관련

## 이진 탐색 트리(BST)란 무엇인가

이진 탐색 트리(Binary Search Tree)는 **탐색을 빠르게 하기 위해 정렬 규칙을 가진 이진 트리**이다.

각 노드는 최대 두 개의 자식 노드를 가질 수 있고, 다음 규칙을 따른다.

```text
왼쪽 자식 < 부모 노드 < 오른쪽 자식
```

즉, 부모보다 작은 값은 왼쪽에, 부모보다 큰 값은 오른쪽에 저장된다.

```text
        8
      /   \
     3     10
    / \      \
   1   6      14
```

위 트리에서 `6`을 찾는다면 다음처럼 탐색한다.

```text
1. 6은 8보다 작다 -> 왼쪽으로 이동
2. 6은 3보다 크다 -> 오른쪽으로 이동
3. 6을 찾음
```

### 특징

- 각 노드는 최대 두 개의 자식 노드를 가진다.
- 왼쪽 서브트리에는 부모보다 작은 값이 저장된다.
- 오른쪽 서브트리에는 부모보다 큰 값이 저장된다.
- 정렬 규칙 덕분에 전체 데이터를 모두 보지 않고 탐색할 수 있다.

### 시간복잡도

| 작업 | 평균 | 최악 |
|---|---:|---:|
| 탐색 | O(log n) | O(n) |
| 삽입 | O(log n) | O(n) |
| 삭제 | O(log n) | O(n) |

트리가 균형 잡혀 있으면 탐색 범위가 절반씩 줄어들어 `O(log n)`이다.  
하지만 한쪽으로 치우친 트리가 되면 연결 리스트처럼 동작해서 최악의 경우 `O(n)`이 된다.

```text
1
 \
  2
   \
    3
     \
      4
```

### 정리

- BST는 정렬 규칙을 가진 이진 트리이다.
- 왼쪽에는 작은 값, 오른쪽에는 큰 값이 저장된다.
- 균형이 잡히면 탐색, 삽입, 삭제가 평균 `O(log n)`이다.
- 한쪽으로 치우치면 최악의 경우 `O(n)`이 된다.

## 힙(Heap)이란 무엇인가

힙은 **최댓값이나 최솟값을 빠르게 찾기 위해 사용하는 완전 이진 트리 기반 자료구조**이다.

힙은 부모와 자식 사이에 일정한 우선순위 규칙을 가진다.

### 완전 이진 트리

힙은 완전 이진 트리 형태를 가진다.  
완전 이진 트리는 마지막 레벨을 제외하고 모든 노드가 채워져 있으며, 마지막 레벨은 왼쪽부터 채워지는 트리이다.

```text
        10
      /    \
     7      5
    / \    /
   3   2  1
```

### 힙의 종류

힙은 크게 최대 힙과 최소 힙으로 나뉜다.

**최대 힙(Max Heap)**

부모 노드가 자식 노드보다 크거나 같은 힙이다.  
가장 큰 값이 루트에 위치한다.

```text
부모 >= 자식
```

**최소 힙(Min Heap)**

부모 노드가 자식 노드보다 작거나 같은 힙이다.  
가장 작은 값이 루트에 위치한다.

```text
부모 <= 자식
```

### 특징

- 최댓값 또는 최솟값을 빠르게 찾을 수 있다.
- 루트 노드에 가장 우선순위가 높은 값이 위치한다.
- 전체가 완전히 정렬된 구조는 아니다.
- 우선순위 큐를 구현할 때 자주 사용된다.

### 시간복잡도

| 작업 | 시간복잡도 |
|---|---:|
| 최댓값/최솟값 확인 | O(1) |
| 삽입 | O(log n) |
| 삭제 | O(log n) |

루트 값을 확인하는 것은 바로 가능하므로 `O(1)`이다.  
삽입이나 삭제는 힙의 규칙을 유지하기 위해 위아래로 노드를 이동시켜야 하므로 `O(log n)`이다.

### 사용 사례

- 우선순위 큐
- 작업 스케줄링
- 다익스트라 최단 경로 알고리즘
- 힙 정렬
- 가장 크거나 작은 값 빠르게 찾기

### 정리

- 힙은 완전 이진 트리 기반 자료구조이다.
- 최댓값이나 최솟값을 빠르게 찾기 위해 사용한다.
- 최대 힙은 가장 큰 값이 루트에 온다.
- 최소 힙은 가장 작은 값이 루트에 온다.
- 우선순위 큐 구현에 자주 사용된다.

## 그래프를 표현하는 방법 두 가지

그래프를 표현하는 대표적인 방법은 **인접 행렬**과 **인접 리스트**이다.

### 인접 행렬(Adjacency Matrix)

인접 행렬은 그래프의 연결 관계를 **2차원 배열**로 표현하는 방식이다.

```text
  A B C
A 0 1 1
B 1 0 0
C 1 0 0
```

위 예시는 `A-B`, `A-C`가 연결되어 있다는 뜻이다.

**특징**

- 두 정점이 연결되어 있는지 빠르게 확인할 수 있다. → `O(1)`
- 모든 정점 간의 관계를 저장하므로 메모리를 많이 사용한다. → `O(V²)`
- 간선이 많은 그래프에 적합하다.

### 인접 리스트(Adjacency List)

인접 리스트는 각 정점마다 **연결된 정점 목록**을 저장하는 방식이다.

```text
A -> B, C
B -> A
C -> A
```

위 예시는 `A-B`, `A-C`가 연결되어 있다는 뜻이다.

**특징**

- 실제 연결된 간선만 저장하므로 메모리를 적게 사용한다. → `O(V + E)`
- 특정 정점과 연결된 노드를 순회하기 좋다.
- 두 정점이 직접 연결되어 있는지 확인하려면 리스트를 탐색해야 한다.
- 간선이 적은 그래프에 적합하다.

### 비교

| 구분 | 인접 행렬 | 인접 리스트 |
|---|---|---|
| 저장 방식 | 2차원 배열 | 연결된 정점 목록 |
| 메모리 | O(V²) | O(V + E) |
| 연결 여부 확인 | O(1) | O(차수) |
| 인접 노드 순회 | O(V) | O(차수) |
| 적합한 경우 | 간선이 많은 그래프 | 간선이 적은 그래프 |

### 정리

- 인접 행렬은 2차원 배열로 연결 관계를 표현한다.
- 인접 리스트는 각 정점마다 연결된 정점 목록을 저장한다.
- 연결 여부를 빠르게 확인하려면 인접 행렬이 유리하다.
- 메모리를 아끼고 인접 노드 순회를 많이 한다면 인접 리스트가 유리하다.

## BFS와 DFS의 차이

BFS와 DFS는 그래프나 트리를 탐색하는 대표적인 방법이다.

### BFS(Breadth-First Search)

BFS는 **가까운 노드부터 차례대로 탐색하는 방식**이다.  
시작 노드에서 가까운 노드를 먼저 보고, 그다음 거리의 노드를 탐색한다.

BFS는 보통 **큐(Queue)** 를 사용한다.

```text
1. 시작 노드를 큐에 넣는다.
2. 큐에서 노드를 꺼낸다.
3. 꺼낸 노드와 연결된 노드를 큐에 넣는다.
4. 큐가 빌 때까지 반복한다.
```

**사용 사례**

- 최단 거리 탐색
- 미로에서 최소 이동 횟수 찾기
- 네트워크에서 가까운 노드 탐색
- 레벨 순회

### DFS(Depth-First Search)

DFS는 **한 방향으로 최대한 깊게 들어간 뒤, 더 이상 갈 수 없으면 되돌아오는 방식**이다.

DFS는 보통 **스택(Stack)** 또는 **재귀 함수**를 사용한다.

```text
1. 시작 노드에서 탐색을 시작한다.
2. 연결된 노드 중 하나로 깊게 이동한다.
3. 더 이상 갈 수 없으면 이전 노드로 돌아간다.
4. 모든 노드를 방문할 때까지 반복한다.
```

**사용 사례**

- 모든 경로 탐색
- 백트래킹
- 사이클 탐지
- 조합/순열 탐색
- 깊은 구조 탐색

### BFS와 DFS 비교

| 구분 | BFS | DFS |
|---|---|---|
| 탐색 방식 | 가까운 노드부터 탐색 | 한 방향으로 깊게 탐색 |
| 자료구조 | 큐 | 스택, 재귀 |
| 장점 | 최단 거리 탐색에 유리 | 모든 경로 탐색에 유리 |
| 대표 사용 사례 | 최단 거리, 레벨 순회 | 백트래킹, 경로 탐색, 사이클 탐지 |

### 정리

- BFS는 가까운 노드부터 넓게 탐색한다.
- DFS는 한 방향으로 깊게 탐색한다.
- 최단 거리를 구해야 하면 BFS가 적합하다.
- 모든 경로나 경우의 수를 탐색해야 하면 DFS가 적합하다.
