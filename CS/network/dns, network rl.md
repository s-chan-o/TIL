# DNS, Network 관련

## 주소창에 google.com을 입력하면 어떤 일이 일어나나

1. 브라우저가 입력한 주소를 URL로 파싱하고, 프로토콜, 도메인, 포트, 경로를 해석한다.

2. DNS 조회로 도메인에 대응하는 IP 주소를 찾는다.
   브라우저 캐시, OS 캐시, hosts 파일, 로컬 DNS 서버 순으로 확인하고,
   없으면 루트 DNS, TLD DNS, 권한 DNS를 거쳐 최종 IP를 얻는다.

3. 얻은 IP의 443 포트로 TCP 3-way handshake를 수행해 연결을 맺는다.

4. HTTPS 통신을 위해 TLS 핸드셰이크를 진행하고,
   서버 인증서를 검증한 뒤 세션 키를 합의한다.

5. 브라우저가 HTTP 요청을 보내고,
   서버는 이에 대한 HTML 응답을 반환한다.

6. 브라우저는 HTML을 파싱해 DOM을 만들고,
   CSS, JS, 이미지 같은 추가 리소스를 요청한 뒤 화면을 렌더링한다.

## DNS가 무엇이고 어떻게 동작하나

DNS는 사람이 읽을 수 있는 도메인 이름을 IP주소로 변환하는 분산 시스템이다. 

**동작 방식**
1. 브라우저가 먼저 사진의 DNS 캐시를 확인한다.
2. 브라우저 캐시에 없으면 OS 캐시와 '/etc/hosts' 파일을 확인한다.
3. 그래도 없으면 로컬 DNS 서버에 질의한다.
4. 로컬 DNS 서버에도 캐시가 없으면 루트 DNS 서버 주소를 반환한다.
5. 루트 DNS 서버는 해당 도메인의 TLD DNS 서버 주소를 반환한다.
6. TLD DNS 서버는 권한 DNS 서버 주소를 반환한다.
7. 권한 DNS 서버가 최종 IP 주소를 반환하면, 이 결과가 로컬 DNS 서버와 브라우저로 전달된다.

## IP 주소, 서브넷 마스크

**IP 주소**

네트워크 상의 장치를 식별하는 32비트(IPv4) 주소이다.

- 공인IP : 인터넷에서 직접 사용되는 고유 주소
- 사설IP : 내부 네트워크에서만 사용

**서브넷 마스크**

네트워크 부분과 호스트 부분을 구분하는 값이다.

**NAT**

사설 IP를 공인 IP로 변환해 인터넷에 접속하게 해준다.
여러 디바이스가 하나의 공인 IP를 공유할 수 있어 IP 주소 절약에 기여한다.

## OSI 7계층

OSI 7계층은 네트워크 통신 과정을 7단계로 나눈 참조 모델이다.

**장점**
- 통신 과정을 단계별로 나누어 이해하기 쉽다.
- 장애가 발생했을 때 어느 계층에서 문제가 생겼는지 파악하기 쉽다.
- 서로 다른 회사의 장비와 프로토콜도 표준 기준으로 통신할 수 있다.

### 1계층 - 물리 계층 (Physical Layer)

전기적, 기계적 신호를 이용해 실제 데이터를 전송하는 계층이다.

- 단위 : Bit
- 장비 : Hub, Repeater, 케이블

### 2계층 - 데이터 링크 계층 (Data Link Layer)

물리 계층을 통해 전달되는 데이터의 오류와 흐름을 관리하고, MAC 주소를 이용해 같은 네트워크 내에서 통신할 수 있게 해주는 계층이다.

- 단위 : Frame
- 장비 : Bridge, Switch
- 프로토콜 : Ethernet, PPP, HDLC

### 3계층 - 네트워크 계층 (Network Layer)

IP 주소를 이용해 목적지까지의 경로를 결정하고, 데이터를 패킷 단위로 전달하는 계층이다.

- 단위 : Packet
- 장비 : Router
- 프로토콜 : IP, ICMP, OSPF, BGP

### 4계층 - 전송 계층 (Transport Layer)

데이터를 신뢰성 있게 전달하고, 포트 번호를 이용해 적절한 응용 프로그램에 연결해주는 계층이다. 오류 검출, 흐름 제어, 재전송 기능도 담당한다.

- 단위 : Segment
- 프로토콜 : TCP, UDP

### 5계층 - 세션 계층 (Session Layer)

통신 세션을 연결, 유지, 종료하는 계층이다.

- 단위 : Data, Message
- 프로토콜 : NetBIOS, RPC, PPTP

### 6계층 - 표현 계층 (Presentation Layer)

데이터 형식을 변환하고, 인코딩, 압축, 암호화 등을 처리하는 계층이다.

- 단위 : Data, Message
- 프로토콜 : SSL/TLS, JPEG, MPEG

### 7계층 - 응용 계층 (Application Layer)

사용자가 직접 접하는 계층으로, 네트워크 서비스를 제공하는 계층이다.

- 단위 : Data, Message
- 프로토콜 : HTTP, FTP, SMTP, DNS

**통신 과정**

1. 송신 측은 상위 계층에서 하위 계층으로 내려가며 각 계층의 헤더를 붙인다.
2. 물리 계층을 통해 실제 데이터가 전송된다.
3. 수신 측은 하위 계층에서 상위 계층으로 올라가며 헤더를 제거한다.
4. 최종적으로 응용 계층에서 사용자가 데이터를 확인한다.


## 공인 IP, 사설 IP, NAT

**공인 IP(Public IP)**

인터넷에서 직접 통신 가능한 전 세계 유일한 IP 주소이다. ISP로부터 할당받는다. 

**사설 IP(Private IP)**

내부 네트워크에서만 사용하는 IP 수조이다. 인터넷에 직접 노출되지 않는다.

**NAT(Network Address Translation)**

사설 IP를 공인 IP로 변환해주는 기술이다.
