## Spring Bean 이란?

Spring Bean이란 Spring Ioc 컨테이너에서 관리되는 자바객체(POJO)를 의미한다.

> 역할

- 객체 생성 및 관리, 스프링 빈은 개발자가 직접 객체를 생성할 필요없이 스프링 컨테이너가 대신 만들어준다. -> 의존성 주입 (DI)

- 의존성 관리, 어떤 객체가 다른 객체를 필요로 할때 스프링은 두 객체를 자동으로 매핑해준다.

- 객체 생명주기 관리, 스프링 컨테이너는 스프링 빈의 생명주기도 관리한다. 

> 컨테이너에서 빈 관리 방식

- 싱글톤 스코프 : 

애플리케이션 내에 딱 하나의 빈만 생성해서 사용하는 방식이다.

- 프로토타입 스코프: 

요청이 있을때마다 새로운 빈을 생성하는 방식이다. 

> 등록 방법

- XML 파일

- 클래스에 어노테이션을 등록하여 빈 등록

- 자바 설정 파일

> 사용이유

스프링 빈을 활용하면 코드의 의존성을 줄이고, 유지보수성을 높일 수 있다.
